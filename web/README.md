# Chosy.ai Landing Page

Static landing page for [chosy.ai](https://chosy.ai) — vanilla HTML + CSS, no framework.

**Local preview:** `npx serve web` or open `web/index.html` directly in a browser.

**Deploy:** Vercel > Import repo > Root Directory: `web` > Deploy.

**Custom domain:** Point `chosy.ai` DNS to Vercel (CNAME or nameservers).
